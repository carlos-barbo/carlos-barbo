## 🚀 Featured Project

### WhatsApp-integrated CRM & Customer Support Platform

Fullstack platform combining CRM, customer support, automations, sales funnels and AI agents, all integrated with WhatsApp. Full-stack contribution with a strong technical focus, building robust backend APIs and functional frontend interfaces, always prioritizing correct behavior and business-rule consistency.

- Built and maintained REST APIs with **Node.js, Express and TypeScript**, backed by **PostgreSQL and Sequelize**
- Implemented real-time features with **Socket.IO and Redis** (queues, company/ticket-scoped events)
- Built complex modules such as **2FA**, automation-funnel control, a prompt editor for AI agents, sales pipelines, and queue-based permission systems
- Developed **React + Material UI** interfaces focused on component behavior and business-rule consistency
- Integrated **WhatsApp via Baileys and the Meta API**, including 24-hour conversation-window handling and dedicated microservices
- Worked across **DevOps**: process automation, containerization with **Docker**, and CI/CD improvements

**Stack:** TypeScript · Node.js · Express · PostgreSQL · Sequelize · React · Material UI · Socket.IO · Redis · Docker · RabbitMQ
